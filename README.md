# My Transformation App 💪

Your personal fitness & nutrition tracker — meals, macros, training, body measurements and trends.

---

## 🚀 Deploy to Vercel (FREE — 5 minutes)

### Step 1 — Create a free Vercel account
Go to **https://vercel.com** → Sign Up → continue with GitHub or email.

### Step 2 — Upload your project
1. Go to **https://vercel.com/new**
2. Click **"Browse"** to upload files (you don't need GitHub)
3. Drag and drop the entire **transformation-app** folder
4. Vercel auto-detects it as a Vite/React project

### Step 3 — Deploy settings (leave as default)
- Framework: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Click **Deploy** → wait ~60 seconds

### Step 4 — Your app is live! 🎉
You'll get a URL like: `https://my-transformation-xyz.vercel.app`

---

## 📱 Install on iPhone as an App

1. Open your Vercel URL in **Safari**
2. Tap the **Share button** (square with arrow)
3. Scroll down → tap **"Add to Home Screen"**
4. Name it "My Transformation" → tap **Add**
5. It's now on your home screen like a real app! 🙌
